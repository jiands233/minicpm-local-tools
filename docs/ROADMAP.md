# 项目方向与范围

主线是本地阅读日报：从用户指定的浏览历史生成可核对的记录列表，并可用本地 MiniCPM5-2B 进行主题归类。先做好文档、合成演示和真实环境验收，分类结果始终需要人工检查。

当前冻结功能范围，仅修复缺陷、补测试与文档，以及为阅读日报增加标题信息不足时的确定性兜底、合成演示和用户于 2026-11-12 授权的小票展示层。小票首版提供本地 HTML 详单与省略明细的分享 HTML；PNG 导出后续再评估。剪贴板、文件夹搜索、音频和命令助手继续保留为实验。

- 不抓取网页正文，不推算阅读时长或用户观点。
- 不增加云端回退或全盘采集，不自动更改系统权限。
- 不做 Hermes 插件；截图 OCR 只描述现有中英文能力。
- 会议待办质量未达标，不作为主线展示。
- 搜索的向量 JSON 全表加载属于已知限制，暂不重构；有真实大目录需求时再评估。

后续验收包括 Chrome 真实历史、Safari 权限、整机断网以及合成样例；真实历史只记录计数，不提交标题或链接。实现与验收进展见[迭代记录](PROGRESS.md)，使用方法见[阅读日报说明](history.md)。
