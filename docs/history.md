# 每日本地阅读回顾

这份日报整理浏览器访问记录：程序保留原始标题和脱敏链接，本地模型可按标题与域名分组。它不读取网页正文，也不生成逐页摘要或推断你是否读完；主题分类可能出错，链接脱敏后也可能无法返回原页面。

摘要模式下，标题为空、与域名相同或精确匹配通用标题（如“首页”“Home”“New Tab”）的记录不送模型，归入“标题信息不足，未归类”；规则不会识别所有含糊标题。全是这类记录时不调用模型。列表模式不做主题分组。

## 虚构样例

安装基础依赖后，运行 `.venv/bin/mcpm history --demo` 即可查看样例，不读取个人历史、不连接模型或网络。页面记录是虚构的；主题来自一次预录的本机 MiniCPM5-2B Q4_K_M 输出，运行时仍检查编号是否完整、重复或越界。模型把 Python 和海洋内容合成了一个主题，这是实际保留的分类错误，不代表正确归类；链接使用保留域名，仅用于演示。报告可直接查看 [sample-report.md](../examples/reading-demo/sample-report.md)。

如果已准备好本地模型，可在新建的临时目录生成相同虚构数据库，再运行真实摘要作对照：

```sh
demo_dir=$(mktemp -d)
.venv/bin/python examples/reading-demo/make_history.py "$demo_dir/History"
.venv/bin/mcpm history --database "$demo_dir/History" --date 2026-11-12 --mode summary
```

对照结果每次由模型重新生成，可能与预录主题不同或因校验失败而拒绝输出。完成后可删除该临时目录；数据库仅含虚构数据。`--demo` 固定使用样例，只允许搭配输出格式和输出目录，不接受其他数据选择或模型选项。

## 阅读小票

小票复用同一套历史读取、过滤和主题校验。`--format receipt` 生成自包含 HTML：主题下直接列出可点击的页面标题、域名和访问次数；指定输出目录时，同时保存原 Markdown。`--format receipt-share` 只生成独立的分享 HTML，文件源码也不包含明细标题、URL 或域名。主题名仍可能涉及隐私，分享前请检查；本版不提供带标题分享开关。

```sh
# 虚构样例：不读私人历史、不联网、不调用模型
.venv/bin/mcpm history --demo --format receipt --output-dir outputs/receipt-demo
.venv/bin/mcpm history --demo --format receipt-share --output-dir outputs/receipt-demo
# 自己的历史：先关闭浏览器，并启动本地模型服务
.venv/bin/mcpm history --date yesterday --mode summary --format receipt --output-dir outputs/reading
```

用浏览器打开生成的 HTML 即可查看，无需启动 Web 服务；样式内嵌，不加载远程字体或图片。省略输出目录时 HTML 输出到终端。日期取筛选自然日；“访问记录”为过滤且去重后的页面数，站点为不同域名数，主题条数为该组页面数，不是阅读时长或读完数。

默认仍输出 Markdown。list 模式的小票标明未作主题归类；摘要失败时仍拒绝输出，需显式改用 `--mode list`，不会为了出小票编造主题。空列表和近似快照警告也会出现在小票中。长列表完整显示，可滚动查看；未做截断或排名。

输出文件为 `{日期}-reading.html`、`{日期}-reading.md`；分享版为 `{日期}-reading-share.html`，不同时导出私人 Markdown。所有文件拒绝覆盖，建议每次选新目录；成对写入非跨文件原子操作，普通失败尽力清理本次文件，强制终止仍可能留下一部分。

浏览器打印样式已提供，可自行打印或保存 PDF。当前没有 CLI PNG 导出，中文打印分页和各浏览器 PDF 效果尚未验收。虚构演示依然保留预录模型将 Python 与海洋内容错误合组的情况。

```sh
.venv/bin/mcpm history --browser chrome --date yesterday
.venv/bin/mcpm history --browser safari --date 2026-11-12 --mode summary --output-dir outputs/reading
.venv/bin/mcpm history --database '/path/to/profile/History' --date today
# 仅当你理解并接受未提交数据风险，才对锁定的 Chrome 显式启用近似快照：
.venv/bin/mcpm history --browser chrome --date yesterday --allow-approximate-snapshot
```

默认 Chrome 的 Default profile；Safari 可能需要在系统设置中授予终端完整磁盘访问权限。不会自动更改权限。数据库路径可显式指定。优先通过 SQLite backup API 获取包含已提交 WAL 的临时快照，源数据库使用只读连接。只查询指定自然日，正常结束后删除快照。进程被强制终止或系统异常时，私有临时目录可能残留，包含浏览历史；请检查系统临时目录的 `mcpm-history-*` 文件夹后再删除。

部分运行中的 Chrome 会持有独占锁，导致正常 backup 持续被锁定。**默认会停止并提示先关闭浏览器，不自动复制被锁定的数据库。** 这确保默认路径不会因为读取不到一致快照而悄悄生成结果。

仅 Chrome 显式指定 `--allow-approximate-snapshot` 才在锁定时尝试无锁复制。它可能读到未提交的数据，即使 SQLite `integrity_check` 返回通过也无法保证事务一致；这不仅是理论风险：在合成 SQLite `journal_mode=OFF` 的独占写事务中，脏页已写到数据库，复制通过完整性检查却读到了未提交内容，存在陈旧零头日志时同样如此。复制会在 stderr 和生成的 Markdown 中显示风险提示；使用摘要模式时，近似快照中的记录也可能送给本机模型。需要一致结果请关闭浏览器，使用默认模式。

即使显式选择近似复制，程序仍拒绝数据库或父路径含符号链接、存在 WAL/shm、活动 rollback journal，以及复制或验证期间观察到文件变化的情况，并对副本执行完整性检查。这些检查只能排除部分问题，不能保证一致性。失败时请稍后重试或先关闭浏览器；Safari 不使用该回退。此流程参考 [SQLite 文件锁定与回滚日志说明](https://www.sqlite.org/lockingv3.html)，不更改源数据库。

默认时区 Asia/Shanghai，可用 `--timezone` 更改。保留时间、标题、域名和脱敏 URL；仅合并完全相同的原始 URL 的重复访问次数，不推算阅读时长。原始 URL 的 SHA256 仅在内存中用于去重，不写入报告。这样不同文章即使脱敏后链接一样，也保留为不同记录，避免丢掉主题。

在实行夏令时的时区，回拨时重复的本地小时会显示 UTC 偏移（如 `01:30 -0400` 和 `01:30 -0500`），以区分不同瞬间；其他时间仍显示 `HH:MM`。同一原始 URL 的重复访问仍合并，仅保留第一次访问时间和访问次数。

查询参数默认移除，只有以下公开资源编号例外：精确匹配 youtube.com / www.youtube.com / m.youtube.com 的 `/watch` 页面可保留合法的 11 位 `v` 视频 ID；精确匹配 bilibili.com / www.bilibili.com 的 `/video/` 页面可保留正整数 `p` 分 P 编号。其他参数和片段均隐藏；被隐藏的记录会标注“链接参数已隐藏，可能无法回到原页面”。相似域名、异常编号不进入白名单。仍过滤常见登录、密码、认证、支付路径及明显敏感查询。认证路径按词语或路径边界识别，并对显式凭据参数键及有限层 URL 编码做过滤；作者页面 `authors` 和普通 `author` 参数不会仅因包含 `auth` 被过滤。兼容既有行为的 `session` 参数会从链接隐藏，但不会单凭该参数删除记录。规则不是完整隐私检测，标题和 URL 路径仍可能含敏感内容。

默认列表模式不用模型。summary 模式将记录编号、标题与过滤后 URL 的域名发送给本地 MiniCPM 归类，不发送路径和查询参数，再由程序从原始记录渲染链接。标题可能含敏感内容，请自行检查；网页标题及域名是资料，不应被模型作为指令。模型不能自行添加页面；无效引用会报错。输出不包含文章观点、待办或“你已经读完”的推断。每批最多 60 条，同时将“编号 + 标题 + 域名”的 UTF-8 编码控制在 3600 字节以内；每条标题不在模型输入中拆开，控制字符替换为空格。字节限制是保守估算，不能保证适配任意模型或更小的上下文，分批也可能产生重复主题。当模型返回的 JSON、结构或编号校验失败时，该批会按顺序拆分后重试，单批最多额外 6 次模型调用；模型服务故障或网络/HTTP 错误不会重试。单条失败或预算耗尽时整份摘要失败，建议使用列表模式。重试只验证编号覆盖，不证明主题标签语义正确。曾以本机 Chrome 历史做只读计数验证；未输出或保存页面详情，也未送入模型。

展示时，网页标题和模型主题中的终端控制字符和双向文字控制符转成可见转义；链接中的同类字符做百分号编码，避免在终端预览时被直接解释。这不会改变浏览器历史库，也不是对网页标题或路径的隐私过滤。

`--output-dir` 明确授权保存到该目录，否则只打印预览。按日期命名且不覆盖旧文件；同一天重试可选择另一个目录。
