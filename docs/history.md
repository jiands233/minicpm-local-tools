# 每日本地阅读回顾

```sh
.venv/bin/mcpm history --browser chrome --date yesterday
.venv/bin/mcpm history --browser safari --date 2026-11-12 --mode summary --output-dir outputs/reading
.venv/bin/mcpm history --database '/path/to/profile/History' --date today
```

默认 Chrome 的 Default profile；Safari 可能需要在系统设置中授予终端完整磁盘访问权限。不会自动更改权限。数据库路径可显式指定。先通过 SQLite backup API 获取包含已提交 WAL 的临时快照，再只查询指定自然日；源数据库使用只读连接。程序结束删除快照。

默认时区 Asia/Shanghai，可用 `--timezone` 更改。保留时间、标题、域名和脱敏 URL；仅合并完全相同的原始 URL 的重复访问次数，不推算阅读时长。原始 URL 的 SHA256 仅在内存中用于去重，不写入报告。这样不同文章即使脱敏后链接一样，也保留为不同记录，避免丢掉主题。

查询参数默认移除，只有以下公开资源编号例外：精确匹配 youtube.com / www.youtube.com / m.youtube.com 的 `/watch` 页面可保留合法的 11 位 `v` 视频 ID；精确匹配 bilibili.com / www.bilibili.com 的 `/video/` 页面可保留正整数 `p` 分 P 编号。其他参数和片段均隐藏；被隐藏的记录会标注“链接参数已隐藏，可能无法回到原页面”。相似域名、异常编号不进入白名单。仍过滤常见登录、密码、认证、支付路径及明显敏感查询。规则不是完整隐私检测，标题和 URL 路径仍可能含敏感内容。

默认列表模式不用模型。summary 模式让本地 MiniCPM 按标题归类，再由程序从原始记录渲染链接。模型不能自行添加页面；无效引用会报错。输出不包含文章观点、待办或“你已经读完”的推断。每批最多 60 条，同时将“编号 + 标题”的 UTF-8 编码控制在 3600 字节以内；每条标题保持完整，不在模型输入中拆开。字节限制是保守估算，不能保证适配任意模型或更小的上下文，分批也可能产生重复主题。 当模型返回的 JSON、结构或编号校验失败时，该批会按顺序拆分后重试，单批最多额外 6 次模型调用；模型服务故障或网络/HTTP 错误不会重试。单条失败或预算耗尽时整份摘要失败，建议使用列表模式。重试只验证编号覆盖，不证明主题标签语义正确。真实个人浏览记录未用于项目开发测试。

`--output-dir` 明确授权保存到该目录，否则只打印预览。按日期命名且不覆盖旧文件；同一天重试可选择另一个目录。

验收测试包括 Chrome WAL 中的已提交记录、自然日边界、去重和敏感 URL 过滤。真实模型验收使用人工创建的 SQLite 浏览记录，不代表已经验证 Safari 系统权限。

2026-11-12 实跑：使用三条合成阅读记录和一条登录记录，在本地 MiniCPM5-2B Q4_K_M 上完成主题输出；登录页被过滤，三条保留记录均有来源链接。此前 1B 曾照抄占位主题、结构不合格；现改用简短输入、2B、温度 0，并检查分组是否遗漏或重复记录。模型可能把每个标题独立分组，归纳质量仍需持续改进。
