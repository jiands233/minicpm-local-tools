## 已发生的演化

1. 原始计划是五个独立方向，落地为同一工具集的独立子命令，避免重复模型配置；剪贴板保留原生入口。
2. Ollama 注册库下载被代理 DNS 的假 IP 拦截，改为固定来源 GGUF 下载、SHA256 校验、本地导入。没有修改系统代理配置。
3. 1B 在真实测试中出现照抄格式、漏项和误译；升级默认2B，降低温度为0，关闭推理模式。`chat_template_kwargs` 单独对 Ollama 不够，补充 `reasoning_effort: none`。
4. 搜索自由解释曾编造拒绝理由；改成只接受逐字原文引用，无有效引用就说明不能确认相关性。
5. 音频从自由生成行动项改成引用片段/句子选择，输出由程序还原原句；责任人和时间也必须有原文依据。
6. 命令模型曾把改后缀写成追加后缀，提示改进后修复，但仍会漏防覆盖参数；程序加入独立风险提示，写操作不进入执行白名单。

## 验证原则

自动测试覆盖边界和失败语义，不能证明模型质量；服务 `/models` 可达也不等于功能验收。真实模型证据采用专门编写或合成样本，未冒称真实访谈、个人浏览或会议材料。细节和复现命令在各功能文档；原始输出在本机忽略目录 `.local/validation/`、`outputs/`。

后续按「发现真实失败 → 添加适当回归用例 → 修改 → 重测 → 提交」迭代。优先完善剪贴板实际交互和音频真实场景，再评估 UI、性能、分发；不默认增加云调用或全盘采集。

## 2026-11-12 · 第四轮：索引安全与隔离验收

- 修复可复现的数据丢失风险：此前对任意已存在文件使用搜索 `--replace` 都可能覆盖它。现仅允许同一资料根目录的可验证索引重建；普通文件、其他数据库、损坏文件、符号链接和存在 WAL／日志的数据库会被拒绝。兼容旧版 v1 索引。建立过程中目标变化则拒绝覆盖；最后一次检查与替换之间仍有很小竞态，不应同时由其他进程更改索引路径。
- 隔离验收：独立 Ollama 与验收进程使用 macOS `sandbox-exec` 禁止网络、仅允许本机连接。外网对照连接在普通环境可达，在相同沙箱中被拒绝；隔离实例的日志记录了实际 chat 与 embedding 请求。五项合成样本通过，报告保存在 `.local/validation/network-isolation/mvp-tlpa5mdh/report.json`。这是进程级网络限制，并非整机断网；系统服务/Mach IPC、真实用户数据和物理按键不在验收范围内。
- Chrome Default 的历史库可只读打开并确认所需表存在；只查询了 schema，没有读取个人浏览记录。所用 immutable 模式忽略 WAL，不能证明实际使用时的在线备份流程。Safari 文件存在，但尚未打开或验证 TCC 授权。
- 自动测试：100 项通过，Ruff 通过。真实物理快捷键、Safari 权限、长真实音频和整机断网验收仍未完成。
- 统一音频、搜索和剪贴板文档示例使用项目 `.venv`，避免执行未指定 extra 的 `uv run` 时重新同步并移除已安装的 PDF / 音频依赖。

## 2026-11-12 · 第六轮：完整性与诊断

- 搜索：`os.walk` 以前会静默跳过无法读取的子目录，导致索引不完整，重建时甚至可能替换完整旧索引。现在访问失败即终止并保留旧索引；用临时合成目录的权限错误验证了首次构建和重建。
- 音频：摘要去重现保留结束时间或行动项负责人、截止时间不同的原文引用。完全相同的文本、时间范围和指派仍合并；同一转写段内部重复原文难以区分，不能认为完整说话人证据已经解决。

## 2026-11-12 · 第七轮：过期来源、重试和配置错误

- 文件搜索为新索引记录来源文件元数据，查询时标记检测到的变化；即使没有旧摘录命中也会提示过期。旧 v1 索引没有指纹，显示状态未知，仍可查询和重建。建索引时如果文件状态变化会中止，保护原索引。指纹相同仅表示未检测到变化，不证明内容绝对相同；新增文件也需要重建才能被索引。
- 阅读回顾只针对返回的格式或编号校验错误，按批拆分并有界重试，每个初始批次最多额外 6 次；网络和 HTTP 错误直接返回。普通三条合成标题实测通过。极端 60 条随机长标题样本拆至单条后模型仍虚构编号，工具拒绝输出并建议列表模式，该样本仍未通过。
